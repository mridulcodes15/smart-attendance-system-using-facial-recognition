# Smart Attendance System using Face Recognition

## 🚀 Overview
This project is a Smart Attendance System that uses face recognition to automatically mark attendance.

## 🛠️ Tech Stack
- Python
- OpenCV
- NumPy
- Machine Learning

## 📌 Features
- Real-time face detection
- Face recognition-based attendance
- Automated attendance recording
- Reduces manual effort

2. Install dependencies  
3. Run the main file
